## Features ✨

- **Secure Login**: Enter the birthday key (0803) to access the celebration
- **Animated Title**: Letter-by-letter bounce animation
- **Birthday Information**: 
  - Full birthday date displayed
  - Current age calculated automatically
  - Live countdown to next birthday
- **Floating Balloons**: Colorful balloons that float up the screen
- **Animated Birthday Cake**: With flickering candles
- **Confetti Effects**: Exploding confetti animations
- **Floating Hearts**: Romantic heart particles
- **Interactive Elements**:
  - Click the "Celebrate!" button for full celebration
  - Click balloons to pop them with particle effects
  - Press Space or Enter for quick celebration
  - Move your mouse to tilt the card (3D effect)
- **Background Stars**: Twinkling star animation
- **Sound Effects**: Audio feedback for celebrations
- **Secure Session**: Uses browser session storage for authentication
- **Logout Function**: Securely logout to return to login screen
- **Responsive Design**: Works on mobile, tablet, and desktop

## Customization

### Change Secret Key
Edit in `script.js`:
```javascript
const SECRET_KEY = '0803'; // Change this value
```

### Change Birthday Date
Edit in `script.js`:
```javascript
const BIRTHDAY_DATE = new Date('2006-08-03'); // Change year/month/day
```

### Change the Name
Edit in `index.html`:
```html
<div class="name">ACAA</div>
```
